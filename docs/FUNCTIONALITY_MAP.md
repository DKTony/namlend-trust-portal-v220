## Notes on Partial Wiring

- **IPS adapter**: Phase 4A+4B complete — spec-compliant msgId, transaction limits, timeouts, mTLS config, PIN encryption, reversal, collect, deemed resolution. Production IPS switch connectivity requires BoN certificates (env vars documented in IPS_IMPLEMENTATION.md).
- **Credit scoring UI**: ✅ Fully wired — `submitLoan` schedules `processLoanApplication` action which writes `creditScore`, `debtToIncomeRatio`, and `recommendation` to the `loans` table. `Loan360View` (Overview tab) and `LoanReviewPanel` display these fields.
- **Budget Tracker**: Convex `budgetEntries` / `savingsGoals` / `budgetLimits`; owner-scoped mutations. Re-checked 2026-08-15.
- **Reconciliation**: Convex `reconciliation.ts` has queries; live NTSL/NISS transport is not connected (simulate step remains labelled).
- **TigerBeetle**: Outbox pattern implemented end-to-end; cron worker simulates TB cluster posting unless `TIGERBEETLE_MODE=live`. The config “Test connection” button no longer claims a live TCP session.
- **Admin IPP dashboard**: Wired to `adminListOnboarding` / `adminStartOnboarding` (2026-08-15); was a placeholder.
- **Overdue / collections (payments tabs)**: Real Convex queries as of 2026-08-15; no mock client lists.
- **Branding**: Tenant branding is stored in `institutionConfig`; raster assets use Convex File Storage. Public, loading, unentitled, and failed states retain the bundled OG Financial Services identity.
- **Role assignment**: Admin UI uses `api.users.assignRole`; the legacy Supabase role-assignment helper has been removed.
- **Authorization review items**: 2026-08-15 Wave E — public financial/IPS `assertOwnerOrStaff` call sites now use `assertOwnerOrTenantStaff` (row `institutionId`) or `assertOwnerOrTenantStaffForUser` (`userRoles.institutionId`). Cross-tenant `getLoan` is denied even when `TENANCY_ENFORCEMENT` is off (`lendingLifecycle` Wave E test). The legacy helper remains in `auth.ts` for the comment map only.
- **Institutions admin UI**: `InstitutionsDashboard` is not mounted on `/admin`; live registry is `/platform/tenants`.
- **`/admin/*` route**: `requireLoanOfficer` guard — both `loan_officer` and `admin` roles can access. Admin-only features (user management, system config delete) are gated inside UI components by `isAdmin` check.
- **Collections activity history**: `CollectionsWorkqueue` expanded rows subscribe to `api.collections.listInteractionsByLoan`. PTP/log-contact writes live on `CollectionsDashboard` (`createPromiseToPay`, `recordInteraction`).
- **TigerBeetle ledger chrome**: “Process Queue” / “Run Reconciliation” on `LedgerDashboard` are disabled (outbox is a 30s internal worker; no client drain). IPS health “manual check” is disabled (data is already reactive).
- **Operator chrome honesty (Wave A follow-up)**: Role lock/unlock, payment/client/loan/user Export and Add Client, user 2FA/reset, IPS retry are disabled. Invented `+12%` trends removed from payment/client overview cards.
